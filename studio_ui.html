Baseline vs Moment RAG

Running both pipelines
Baseline semantic search
  • One query vector, one cosine pass
  • Finds chunks that sound like the question
  • Misses relevant chunks that use different words
  • No timestamps back to the video moment
Moment RAG
  • Decompose into sub-queries so each facet retrieves on its own
  • Hybrid retrieve dense, BM25, and HyDE, fused with RRF
  • Cross-encoder rerank scores query and chunk together
  • Timestamp citations jump to the exact moment
